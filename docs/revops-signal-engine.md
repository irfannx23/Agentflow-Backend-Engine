# RevOps Signal Engine

The engine normalizes real product events evaluated by the runtime signal definitions and persisted signals generated by existing Supabase capabilities.

It supports activation, adoption, health, expansion, upsell, cross-sell, renewal, retention, revenue, risk, power-user, inactivity, usage, subscription, lifecycle, and customer-success intelligence.

Customer health and scoring remain owned by `evaluate_account_health` and `current_customer_health`. Cross-sell is returned only when the health evaluation explicitly recommends it. Renewal readiness, retention outcome, and advocacy require explicit inputs. This prevents synthetic marketing events and hidden thresholds.

Signal normalization is idempotent by stable definition and source identity. Dismissed persisted signals do not create active findings. Findings include evidence identifiers and an audit explanation.
