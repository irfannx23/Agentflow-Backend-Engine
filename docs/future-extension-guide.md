# Future Extension Guide

Add a workflow only when a real operational workflow and source event exist. Register metadata, triggers, actions, integrations, credentials, environment names, schemas, runtime policy, documentation, and tests together.

Add a signal only when it can cite a persisted product event or existing database contract. Define stable identity, deduplication, evidence IDs, category, explanation, and tests. Do not infer cross-sell, renewal, advocacy, or churn from unrelated activity.

Future candidates supported by existing extension points include dedicated renewal assessments, explicit advocacy events, and a first-class cross-sell signal. Add them only after product or database sources and business owners are approved.
